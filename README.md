# SOC Learning Journey 🔐

Welcome to my cybersecurity and SOC learning repository.

This repository documents my learning journey toward building foundational skills for a Security Operations Center (SOC) Analyst role. It includes cybersecurity concepts, networking fundamentals, reconnaissance, scanning, enumeration, password attack simulations, reverse shell concepts, MITM basics, Linux commands, and lab-based practice.

The content is based on my hands-on learning activities performed in a controlled virtual lab environment.

## Repository Objective

The purpose of this repository is to:

- Document my cybersecurity and SOC learning progress
- Build a structured technical portfolio
- Practice writing clear security documentation
- Understand SOC-related concepts through hands-on labs
- Develop foundational skills for SOC L1 and Blue Team roles
