# Centralized Logging

## Overview

Centralized logging stores logs from different sources in one central location.

Instead of checking logs separately on each system, centralized logging allows analysts to access important logs from one place.

---

## Benefits of Centralized Logging

Centralized logging helps to:

- Store logs from different sources in one central location
- Easily access important data from log files
- Generate alerts based on defined log metrics
- Quickly share dashboards and log information with others

Key Learning

Centralized logging is important in SOC environments because it helps analysts monitor multiple systems, detect suspicious activity, and investigate incidents from one place.
