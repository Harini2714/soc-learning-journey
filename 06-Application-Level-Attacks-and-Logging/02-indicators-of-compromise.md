# Indicators of Compromise

## Overview

Indicators of Compromise are clues or artifacts that show possible malicious activity in a system or network.

IoCs help security analysts identify whether a system may be affected by an attack or malware.

---

## Common IoCs of Malware Threats

Common IoCs include:

- Abnormal network traffic
- Unexplained bounced emails
- Pop-ups and unwanted ads
- Unauthorized access attempts
- Port scanning attempts
- File modification, deletion, or relocation
- Blue Screen of Death
- Sudden system freeze
- Sudden shutdown
- System crash
- System slowdown
- Longer reboot time
- Unable to install updates
- Security programs disabled automatically
- Browser configuration changes
- Suspicious processes running at startup
