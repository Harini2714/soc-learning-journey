# Networking Notes

## What is a Network?

A network is formed when two or more machines are connected to share data or information.

## Speed Test

A speed test is used to check the speed of an internet connection.

---

## IP Address

An IP address is used to identify a device on a network.

## IPv6

IPv6 is classless. Unlike IPv4, IPv6 does not use traditional IP classes.

---

## MAC Address

MAC stands for Media Access Control.

A MAC address is a unique address assigned to a network interface.

### MAC Address Structure

- The first three sections are usually assigned by the vendor, such as Dell, HP, Acer, etc.
- The remaining sections are unique identifiers assigned to the network device.

---

## Ports

Ports are virtual entry points used by digital devices to communicate with each other over a network.

There are a total of 65,535 ports.

## Why Ports are Important

Ports help identify which service or application is running on a system.

For example:

- Web services use specific ports
- File sharing services use specific ports
- Remote access services use specific ports

---

## Cyber Threats

A cyber threat is an act where an adversary attempts to gain unauthorized access to an organization’s network by exploiting communication paths.

---

## Tactics, Techniques, and Procedures

TTP stands for:

- Tactics
- Techniques
- Procedures

TTPs help explain how attackers plan, perform, and execute cyber attacks.
