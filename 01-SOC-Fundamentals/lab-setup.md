# Virtual Lab Setup

## Objective

Created a virtual cybersecurity lab environment for practicing SOC and cybersecurity concepts safely in an isolated setup.

---

# Environment Setup

## Virtualization Platform

* Oracle VirtualBox

## Operating Systems Installed

* Kali Linux
* Windows 7 VM
* Metasploitable VM

---

# Network Configuration

* Configured Host-Only and NAT networking
* Verified connectivity between virtual machines
* Tested network communication using ping commands

---

# Tools Installed

* VirtualBox Extension Pack
* Kali Linux Security Tools
* RustDesk
* Basic networking utilities

---

# Purpose of the Lab

This lab environment is used for:

* Linux practice
* Networking fundamentals
* Security monitoring concepts
* SOC-related learning
* Cybersecurity hands-on activities

---

# Learning Outcome

Understood how to create and configure a secure virtual lab environment for cybersecurity practice and analysis.
