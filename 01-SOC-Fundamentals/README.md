# SOC Fundamentals

## Objective

Learned the foundational concepts of Security Operations Center (SOC), security operations, SOC workflows, SOC components, SOC analyst responsibilities, and basic Linux/networking commands used in cybersecurity environments.

## Topics Covered

* Security Operations Center (SOC)
* Security Operations & Management
* SOC Workflow
* Key Components of SOC
* SOC Functions & Operations
* SOC Analyst Roles & Responsibilities
* SOC Models
* Basic Linux Commands
* Basic Networking Commands

## Tools & Environment

* Oracle VirtualBox
* Kali Linux
* Linux Terminal

## Learning Outcome

Gained understanding of how SOC teams monitor, detect, analyze, and respond to cybersecurity incidents along with hands-on exposure to Linux terminal and networking commands.

## Additional Concepts

### SOC Workflow

Typical SOC workflow includes:

1. Monitoring security events
2. Detecting suspicious activities
3. Analyzing alerts and logs
4. Investigating incidents
5. Responding and mitigating threats
6. Reporting and documentation

### Key Components of SOC

* SIEM (Security Information and Event Management)
* Log Management
* Threat Intelligence
* Incident Response
* Security Monitoring Tools
* Analysts and Incident Response Teams

## Note

All activities were performed in a virtual lab environment for educational purposes only.
