# SOC Fundamentals Notes

## What is SOC?

A Security Operations Center (SOC) is responsible for protecting an organization against cyber threats. SOC analysts continuously monitor networks, systems, and security events to identify and respond to potential security incidents.

### Key Characteristics

* Centralized Unit
* Single Point of View
* Situational Awareness and Real-Time Alerting

---

# Security Operations and Management

Security management consists of a set of security activities performed by organizations to maintain an adequate security posture.

## Key Areas

### Security Infrastructure

Implementing adequate information security controls.

### Security Prevention

Assuring security through vulnerability management and penetration testing.

### Compliance and Validation

Complying and validating with various security standards.

### Security Operations

Monitoring, detecting, and responding to incidents.

---

# Security Operations

Security operations involve maintaining and managing a secure IT environment through continuous monitoring and execution of security processes and services.

## Main Functions

* Security Monitoring
* Security Incident Management

---

# Need for SOC

* Respond faster to cyber threats
* Maintain better control over security resources
* Minimize business impact and losses
* Monitor and manage privileged user activities
* Reduce security vulnerabilities
* Customize security monitoring tools

---

# Core Functions of SOC

* Monitoring
* Detection
* Analysis
* Response

---

# SOC Operations

* Log Collection
* Log Retention and Archival
* Log Analysis
* Event Correlation
* Incident Management
* Threat Identification
* Reporting

---

# SOC Analyst Responsibilities

SOC Analysts are responsible for monitoring and investigating security-related activities within an organization.

## Responsibilities

* Monitor and triage alerts and events from multiple sources
* Perform initial analysis and prioritization of alerts
* Escalate incidents to Incident Response (IR) teams when required
* Assist in incident investigation and remediation activities

---

# Key Components of SOC

* People

---

# Types of SOC Models

## In-House SOC

Security operations managed internally within the organization.

## Outsourced SOC

Security operations handled by third-party service providers.

## Hybrid SOC

Combination of internal and outsourced SOC operations.
