# Basic Networking Commands

## Ping Google

Checks internet connectivity.

```bash
ping google.com
```

## Ping DNS Server

Checks connectivity to Google's public DNS server.

```bash
ping 8.8.8.8 -c5
```

## ip a

Displays IP address information.

```bash
ip a
```

## route -n

Displays routing table information.

```bash
route -n
```

## ip r

Displays routing and gateway information.

```bash
ip r
```

## curl ifconfig.me

Displays public IP address.

```bash
curl -s ifconfig.me
```

## curl ifconfig.me -4

Displays IPv4 public IP address.

```bash
curl -s ifconfig.me -4
```
