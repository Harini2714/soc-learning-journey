# Linux Basic Commands

## Terminal Shortcuts

### Open Terminal

```bash
Ctrl + Alt + T
```

### Increase Font Size

```bash
Ctrl + Shift + +
```

### Decrease Font Size

```bash
Ctrl + -
```

---

# System Information Commands

## uname

Displays operating system information.

```bash
uname
```

## uname -a

Displays detailed system information.

```bash
uname -a
```

## whoami

Displays current logged-in user.

```bash
whoami
```

## hostname

Displays system hostname.

```bash
hostname
```

## uptime

Displays current time, uptime, and system load.

```bash
uptime
```

# File & Directory Commands

## pwd

Displays current working directory.

```bash
pwd
```

## ls

Lists files and directories.

```bash
ls
```

## cd

Changes directory.

```bash
cd
```

## mkdir

Creates a new directory.

```bash
mkdir foldername
```

## touch

Creates a new file.

```bash
touch filename.txt
```

## cat

Displays file contents.

```bash
cat filename.txt
```

## head

Displays first 10 lines of a file.

```bash
head filename.txt
```

## tail

Displays last lines of a file.

```bash
tail -n 3 filename.txt
```

## rm -rf

Deletes files/directories forcefully.

```bash
rm -rf foldername
```

## history

Displays previously executed commands.

```bash
history
```
