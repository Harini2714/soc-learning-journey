# Network Scanning and Enumeration

## Objective

This section documents my learning on live host discovery, network range identification, Nmap scanning, NSE scripts, SMB ports, and SMB user enumeration in a virtual lab environment.

## Topics Covered

- Live host discovery
- Network range identification
- CIDR basics
- Nmap scanning
- Nmap Scripting Engine
- SMB ports 139 and 445
- SMB user enumeration

## Lab Environment

- Kali Linux
- Metasploitable VM
- VirtualBox

## Learning Outcome

Understood how network scanning helps identify active systems, open ports, running services, and SMB-related information in a controlled lab setup.

## Note

All activities were performed only in a virtual lab environment for educational purposes.
